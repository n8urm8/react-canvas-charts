## What belongs here

- High-level concepts and usage patterns.
- Feature guides that cut across multiple components.
- Explanations that help an AI answer "how do I use this library?" without reading the demo website first.

## What does not belong here

- Demo-only implementation details.
- Website routing or marketing copy.
- API surface details that are already captured in the package source and component docs.
